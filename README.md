## About AROST.cast

AROST.cast is a customizable input visualization application for Windows.

Originally developed as **Floob's KeyCast**, the project has been rebuilt and rebranded around a new interface, expanded controller support, improved customization, profiles, themes, automatic updating, and a redesigned overlay system.

AROST.cast can display keyboard, mouse, Xbox-style controller, and PlayStation-style controller inputs in real time without requiring accounts, cloud services, or unnecessary background services.

Whether you're recording gameplay, streaming, demonstrating controls, or simply want a visual representation of your inputs, AROST.cast is designed to stay lightweight and out of the way.

---

# ✨ Features

## ⌨️ Keyboard Overlay

Create a keyboard overlay containing the inputs you actually want to display.

- Real-time keyboard input visualization
- Select individual displayed keys
- WASD quick preset
- IJKL quick preset
- MMO-oriented preset
- Custom keyboard layouts
- Adjustable keyboard scale
- Adjustable key spacing
- Adjustable spacebar sizing
- Configurable pressed and unpressed appearances
- Key press animations
- Optional Press Down effect
- Custom key colors
- Custom text colors
- Glow effects
- Adjustable border styling

Changes are previewed directly inside the AROST.cast editor.

---

## 🖱️ Mouse Overlay

Display mouse activity alongside the keyboard.

Supported inputs include:

- Left click
- Right click
- Middle mouse button
- Side mouse buttons
- Scroll activity
- Mouse movement visualization

The mouse can be positioned independently relative to the keyboard and its distance from the keyboard can be adjusted.

---

## 🎮 Controller Overlay

AROST.cast supports dedicated controller visualization alongside its keyboard and mouse system.

### Xbox-style controllers

Visualize:

- Face buttons
- D-pad
- Left and right analog sticks
- Stick clicks
- Shoulder buttons
- Analog triggers
- Menu/view controls

### PlayStation / DualSense-style controllers

AROST.cast also includes a dedicated PlayStation-style visualization rather than simply displaying PlayStation input through an Xbox layout.

Supported inputs include:

- Cross / Circle / Square / Triangle
- D-pad
- Analog sticks
- L3 / R3
- L1 / R1
- L2 / R2
- Menu controls

Controller detection and input handling are designed to work with standard controllers as well as a wider range of compatible and modified devices.

# 💾 Profiles

Different games and setups do not need to share the same configuration.

AROST.cast profiles allow you to maintain multiple complete configurations.

Profiles can be:

- Created
- Activated
- Renamed
- Duplicated
- Favorited
- Deleted
- Imported
- Exported

Profiles preserve the settings needed to quickly move between different overlay setups.

---

## 🔗 Game Linking

Profiles can be associated with games and applications.

AROST.cast includes game discovery designed to make locating installed games easier, including support for common game libraries and running applications.

This allows individual configurations to be organized around the games or applications they were created for.

---

# 📦 Portable AROST.cast Profiles

Configurations can be exported as portable:

`.arostcast`

files.

These files make it possible to:

- Back up a profile
- Move a configuration between computers
- Share a setup
- Import previously created configurations

Legacy `.keycast` profiles from Floob's KeyCast remain importable for backwards compatibility.

---

# 🖥️ Overlay Controls

The overlay is separate from the main AROST.cast editor.

From AROST.cast you can:

- Show the overlay
- Hide the overlay
- Unlock it
- Reposition it
- Resize it
- Lock it back into place
- Restore default positioning

When unlocked, the overlay can be manipulated directly on the desktop.

Once locked, it returns to being a non-intrusive input display.

---

# 📍 Position & Scale

AROST.cast includes controls for positioning the overlay around the screen.

The editor provides:

- Screen-position presets
- Keyboard scaling
- Mouse distance adjustment
- Direct unlocked-overlay positioning
- Direct overlay scaling

This allows the overlay to work with different games, recordings, resolutions, and desktop layouts.

# 🪟 AROST.cast Editor

The editor has been redesigned around a compact glass interface.

The primary sections are:

| Section | Purpose |
|---|---|
| **KBM** | Keyboard and mouse configuration |
| **Controller** | Controller visualization and configuration |
| **Theme** | Application appearance |
| **Profiles** | Saved configurations and game-linked profiles |
| **Settings** | Application-level settings |

The editor can be resized between:

**885 × 570 minimum**

and

**1180 × 760 maximum**

while retaining the same interface structure.

---

# 🐾 AROST Mascot

The Floob's KeyCast identity has been replaced with the new **AROST** visual identity.

AROST.cast includes its own mascot and branding throughout the editor, application iconography, installer, and interface.

The mascot is integrated directly into the application window while remaining visually separate from the configuration workspace.

---

# 🔄 Automatic Updates

AROST.cast includes an integrated update system.

When a newer release is available, the application can:

1. Detect the update
2. Download the new release
3. Close the existing AROST.cast process
4. Launch the updater/installer
5. Replace the previous installation
6. Relaunch the updated application

Additional process cleanup is included to prevent an older AROST.cast instance from keeping application files locked during an update.

---

# 🛡️ Configuration Recovery

AROST.cast is designed to preserve user configurations between versions.

The application maintains configuration history so previous settings can be recovered if necessary.

Legacy Floob's KeyCast data is also migrated into the AROST.cast configuration structure where supported.

Existing users should not need to recreate their profiles simply because the application was rebranded.

---

# 🩺 Diagnostics

AROST.cast includes diagnostic functionality intended to make bug reports easier to investigate.

Diagnostic reports can collect relevant application information into a package that can be attached to a bug report without requiring users to manually locate individual application files.

---

# 🎥 OBS / Recording

AROST.cast is designed to work as an input overlay for streaming and recording software.

The overlay can be captured independently from the main configuration editor, allowing the editor to remain hidden while the input visualization appears in a recording or stream.

---

# 🚀 Installation

1. Open the **Releases** page.
2. Download the latest AROST.cast installer.
3. Run the installer.
4. Launch **AROST.cast**.
5. Configure your keyboard, mouse, or controller.
6. Position the overlay.
7. Save your configuration.

Existing Floob's KeyCast users can migrate forward without manually rebuilding their configurations.

# 📁 Application Data

Current AROST.cast data is stored under:

```text
%APPDATA%\AROSTcast
```

Older Floob's KeyCast data can be migrated from the previous application-data location when detected.

# 🔄 Floob's KeyCast → AROST.cast

AROST.cast is the continuation and rebranding of **Floob's KeyCast**.

The change goes beyond replacing the name.

The application has received a redesigned interface, new visual identity, expanded controller support, themes, improved profiles, improved updating, redesigned customization tools, new overlay controls, and substantial reliability improvements.

Legacy compatibility is intentionally retained where practical.

| Floob's KeyCast | AROST.cast |
|---|---|
| Floob's KeyCast | AROST.cast |
| `.keycast` | `.arostcast` |
| `%APPDATA%\FloobsKeyCast` | `%APPDATA%\AROSTcast` |
| Original interface | AROST glass interface |
| Original branding | AROST identity + mascot |

Old `.keycast` files remain importable.
